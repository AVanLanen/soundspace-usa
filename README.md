# SoundSpace USA

Public website reconstruction for [SoundSpace USA](https://www.soundspaceusa.com/), preserving its content and visual identity with responsive navigation, readable sections, high-quality photography, expandable training details and live provider calendars.

Published at https://avanlanen.github.io/soundspace-usa/ through GitHub Pages, `main:/docs`.

- 52 public source responses preserved, with repaired legacy-route aliases and a website review page.
- 127 image entries preserved as unchanged source files in `docs/assets/originals/`, deduplicated by content. Responsive WebP versions are separate and never upscaled.
- Nine uploaded images exceed Squarespace's public 2500px CDN limit. The saved files retain the highest publicly obtainable versions; they are not claimed to contain the larger native-upload pixel dimensions.
- Punchpass handles class passes and attendance; Acuity handles workshop and training registration. Calendars load on demand and retain direct-provider links.
- Native Squarespace forms, shop checkout and member access open their existing provider destinations. No local form pretends to submit data.
- No changes were made in Squarespace. The original site remains independent.

The local reconstruction project contains the original HTML, inventories, build tools and independent content verifier. The `docs/` folder is the deployable static artifact. All links include the `/soundspace-usa/` project prefix.

See [Website review](https://avanlanen.github.io/soundspace-usa/site-review/) for the public findings and improvements.
